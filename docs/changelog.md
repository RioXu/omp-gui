### v0.4.0 验证与目录来源

- 20 项离线测试，以及 4 项本机集成测试通过；包括原生目录、配置缓存、隔离环境中的模型参数覆盖和真实 DeepSeek 流式过程。
- Windows 原生窗口验证了归档列表无新增入口、固定位置时间、过程展开、DeepSeek 已注册模型及参数表单、搜索服务选单、当前项目名称与无项目禁用状态、左右面板宽度拖动。
- 服务管理合并本机 `omp models ls --kind all --json` 和 OMP 官方公开目录：当时附带 89 个服务提供商、22 个搜索条目及支持内置搜索的模型。新注册的本机模型会自动合并。尚未注册的新内置提供商需要更新附带目录，或先使用自定义入口。
- OMP 的 `web/*` 目录包含可选搜索引擎，不等同于每个引擎已认证；现有首选和备用路由读取原生配置，已有凭据继续由 OMP 使用。OAuth 登录仍在 OMP 终端完成。
- 本轮未改动用户的全局模型配置或凭据；写入兼容性验证使用隔离配置，真实模型只读取测试文件。
- CI 配置已加入仓库，本地 fmt、Clippy 与测试通过；远程 CI 尚未运行。



### v0.5.0 会话与视觉更新

- 同一轮的多个模型消息合并展示，历史过程统一收进一个入口，最终总结保持展开；评论仍引用原始消息。
- 展开思考或工具调用保留当前阅读位置，避免跳到会话末尾。
- 读文件只显示一行路径，不可展开；编辑工具使用历史 Diff；其他工具只展示命令与结果代码块。
- 输出期间可继续编辑并发送追加指令，使用 OMP 原生 steering。停止会中断生成并将尚未执行的追加内容恢复为草稿，历史标记未执行；不会悄悄清空新输入。
- 运行会话右侧使用原生 Spinner；深浅主题使用统一语义色、间距和更清楚的次要文本对比度。
- 当时已安装并应用 UI/UX Pro Max，进行 v0.5 界面适配与交互修订。
- 24 项离线测试通过；单独运行真实 DeepSeek steering/stop 集成测试通过。窗口验证了历史折叠、保持滚动位置、代码块和 Diff、运行标识、生成中输入追加内容、停止与草稿恢复。


### v0.6.0 队列与会话修复

- 输出期间的追加默认进入 OMP `followUp` 队列，等待本轮完成。等待项右侧的「指示」将该项提升到原生 steering 队列，接收和中断时机由 OMP 决定；不强制 abort。
- 指令真正被接收前只显示在等待区域，不提前切断会话中的当前工作过程。排队指令执行顺序变化时，历史按实际接收顺序记录。重启时未确认执行的排队输入恢复为草稿，并标注状态未确认。
- 点击项目 + 后未输入内容就切换会话，不保存空的「新建会话」；已有草稿、评论和历史会保留。
- 按 Windows 目录实际身份归一化普通路径、大小写及 `\\?\` 路径，合并同目录项目入口并保留会话；不同位置的同名目录不合并。
- read 工具收到开始事件即显示「正在读取」和 Spinner，结束后显示读取记录，始终不可展开；状态栏也不再残留上一次 read 的执行提示。
- 右下角显示上下文百分比及当前模型的窗口上限，悬停可查看精确 token 数。
- 项目列表、会话、设置、注册表单、工作面板及其他可滚动区域使用 gpui-kit 原生滚动条，滚动或悬停右边缘时显示。
- 29 项离线测试通过；真实 DeepSeek 集成测试验证了 followUp 保持排队及提升为 steering。窗口验证覆盖项目合并、空白会话、滚动条、执行中的 read、当前模型窗口上限和右侧「指示」按钮。
