# 使用与配置

[返回 README](../README.md) · [验证说明](testing.md) · [组件架构](architecture.md)

本页对应当前源码。历史版本的交互差异见[变更记录](changelog.md)。

左侧顶部连接选择器可切换本地或 SSH Linux；以显示器／服务器图标区分环境，点击整行或右侧下箭头展开切换、编辑及新增连接菜单。连接设置、自动部署、profile、远端文件和断线行为见[远程 Linux](remote.md)。OMP 默认从对应运行环境的 PATH 查找，路径留空恢复自动发现；本地／远端都使用组件式目录选择器，不依赖系统文件浏览器，也不设置默认项目目录。

## 项目与会话

鼠标悬停在“项目”标题时显示添加目录的 +；悬停在具体项目行时显示新建会话的 +。点击项目标题可收起或展开其会话列表，不切换当前会话；在收起的项目中新建会话会自动展开该项目。新建且没有消息、草稿、评论、任务或文件快照的 GUI 会话，在切换离开时自动清理，并同步移除 OMP 原生空白记录；外部占用、已有附件、备份或实际原生内容时保留。

新会话直接在项目目录执行，不创建 Git 分支或工作树，也不要求已有 Git 提交。旧工作树会话保留原执行位置；需要直接修改项目目录时，在项目下新建会话。

本地项目按 Windows 实际路径归一化，合并同目录的大小写及 `\\?\` 别名，不合并不同位置的同名目录。远端项目在 Linux 验证实际目录，路径区分大小写；相同路径在不同环境／profile 中独立保存。

GUI 与终端 OMP 使用同一配置目录中的原生项目会话：GUI 新建时立即保存有标题的原生记录，即使尚未发送提示词，也可在该目录的 OMP 会话选择器中找到。已打开项目内，终端保存的新会话、标题和历史约每 2 秒自动同步到 GUI。未落盘的终端临时会话不在同步范围内。不同 OMP profile 的记录不混合。

会话右键可归档、取消归档或删除。删除需要确认，会同步删除原生记录及会话附件，并移除 GUI 中的消息、评论、草稿和历史快照；项目文件保留。终端删除原生记录后，GUI 连续两次扫描确认缺失再移除对应会话，通常需要 2–4 秒；临时写入、不可读文件和替换备份不会直接被当作删除。

归档及取消归档仍只改变 GUI 本地状态，终端原生记录保留。多个会话可以同时运行，切换会话、项目或环境不中断后台输出；侧栏各会话名最右侧的 Spinner 表示仍在运行。归档或删除运行中的会话前需先停止该会话，不影响其他会话。关闭窗口会结束本地 OMP 子进程，远端运行任务则继续由监督服务持有。另一 OMP 进程占用会话时，GUI 可查看同步的历史，待对方释放后连接；删除遇到占用会报错并保留记录。远端空闲连接回收约需 10 秒，删除和空会话清理会等待占用释放。

旧版 GUI 的独立会话记录会迁移到原生项目存储，保留原生会话 ID、附件，以及 GUI 的评论锚点、草稿、归档状态和历史快照。旧私有记录保留为迁移备份，后续以原生项目记录为准；删除 GUI 会话时一并清理匹配的旧备份。原生记录已缺失的旧历史会保留并显示迁移错误，不凭缓存重建模型上下文。

## 输入、排队与评论

- 输入 `@` 选择当前会话目录中的文件。引用以原生标签插入，中文和空格路径自动加引号，提交后由 OMP 读取。
- 将文件拖入输入框，或用 `Ctrl+V` 粘贴图片／复制的文件，显示原生 Attachment 卡片，悬停可移除；普通文字粘贴仍插入文字。导入在后台进行，完成前暂不能发送。
- 附件先保存本地副本，切换会话和重启后保留未发送附件。图片通过 OMP 的原生 `images` 字段发送；其他文件通过带引号的原生文件引用读取。发送失败、断线或停止未执行的排队项时，文字和对应附件一起恢复。
- 单个附件最多 16 MiB，每条消息最多 16 个、合计 32 MiB；目录不作为附件。图片需要当前模型支持视觉输入，或存在可供 OMP 原生视觉回退使用的已配置视觉模型；仅配置纯文本模型时会提示并保留附件。文件内容提取及其截断范围遵循 OMP 原生读取规则。
- 会话左下角的进行中状态使用 Shimmer，已连接／已断开等静态状态保持普通文字。右下角只显示上下文圆环，悬停显示 OMP 返回的已用／总 tokens；OMP 尚未提供数字时显示“未知”。
- 输入开头的 `/` 查看本机命令和技能。`↑↓` 选择，`Tab` / `Enter` 确认，`Esc` 关闭候选。配置命令直接打开对应界面，其他命令补全到输入框后由 `Ctrl+Enter` 执行。
- 空闲时发送开始一轮任务；运行中的追加输入默认进入 OMP `followUp` 队列。等待项的“指示”将该项提升为 steering，接收时机由 OMP 决定，不强制中断当前任务。
- 输入被 OMP 确认接收后才进入正式历史。停止时恢复尚未执行的输入；重启时，未确认执行的输入恢复为草稿并保留状态说明。
- 连续的模型消息按轮次展示。工具调用与中间工作说明默认折叠，最终总结保留展开；思考生成中流式显示，完成后收起。展开过程保留阅读位置。
- 选中回复文字、文件正文或 Diff 代码后可添加评论，Diff 也支持行号选区。评论绑定原始文本或不可变快照，发送后保留引用、意见和关联回应；继续跟进追加记录，只有明确操作才标为已解决。
- “查看当时变更”打开历史快照，“打开当前代码”读取当前磁盘版本；不会把当前文件冒充历史内容，也不会猜测重复片段的新位置。
- Advisor 建议和其他智能体发来的消息使用独立卡片，标明来源；原生 `display: false` 消息保持隐藏。重启和终端导入使用相同的展示规则。

## 文档标签与工作面板

会话回复兼容 `$$` 与公式正文位于同一行的多行写法，避免后续标题、粗体和列表被误当作公式代码块。兼容处理只作用于显示副本，原始回复与评论引用保留。LaTeX 仍显示源码，不提供公式排版。

会话标签固定在最左侧且不可关闭；文件、当前变更及历史变更在独立标签中打开，可同时保留多个并分别关闭。文件标签不带图标，变更标签使用分支图标及鹅黄色文件名，不加“·变更”后缀。收起工作面板或进入设置不关闭文档；切换会话会清理其打开的文档状态，有未保存内容时先确认。

模型输出的行内代码若指向现存文件，可直接点击，例如 `src/main.rs` 或 Windows 绝对路径。项目内同一文件的相对／绝对路径复用一个文件标签；项目外绝对路径也可显式打开并编辑。目录、普通命令、URL 及不存在的本地文件保持代码样式。相对路径不得越出当前会话目录；文件预览仍受 UTF-8 和 2 MB 限制。

左侧项目导航使用原生 Sidebar，项目列表可独立滚动，归档与设置入口固定在底部；项目标题及项目行的 + 仍只在对应区域悬停时出现。左右面板标题、中央文档标签栏统一为 36px 高度，操作区使用原生 Toolbar。

工作面板以 underline tabs 切换变更、文件、任务和子智能体，使用组件内置的指示线滑动与文字颜色过渡；各页使用独立的滚动区域标识。面板背景随深浅主题与左侧导航保持一致：

- **变更**平铺暂存、未暂存和未跟踪的文件。修改及重命名用鹅黄色，新增用绿色，删除用红色，冲突使用警示色。文件名优先使用剩余宽度，目录最多占四成，宽度不足才截断；整行支持选中和点击。
- **文件**使用原生虚拟化目录树，以连续竖线表示层级，目录旁不显示箭头，点击目录行展开或收起。文件状态颜色与变更页一致。
- **任务**按阶段显示带边框的 Marker 列表，保留阶段名称和完成数。每条任务使用状态图标与文字颜色：绿色勾选为完成、蓝色旋转图标为进行中、灰色空心圆为待处理、红色警示图标为受阻；失败、停止及未知状态也有独立标识。正文不重复显示状态标签，悬停图标可查看状态名称，读屏标签保留。长任务自然换行，受阻原因、详情和备注对齐在任务正文下方。OMP 状态回读省略可选展示字段时保留既有内容；明确移除的任务不会恢复。
- **子智能体**展示任务、进度、完成／失败状态与输出，已完成记录保留。点击“查看会话”读取原生子会话，约每 2 秒刷新；支持查看子回复、工具过程、顾问及智能体来信，其中的文件链接同样可点击。该视图只读，不发送子智能体指令。
- 工具过程展开后展示命令或参数及输出，包括智能体发送、等待和任务调用；工具的部分结果也会更新展示与任务状态。
- 文件树、变更列表及打开的当前文档监听磁盘变化自动刷新，保留目录展开状态及阅读位置。历史快照保持不变。
- Diff 对比当前磁盘内容与 Git HEAD；当前没有分别审查暂存区和工作区的两套 Diff。普通非 Git 目录可浏览文件，变更列表为空。
- 查找只针对激活标签。匹配显示计数及高亮；命中折叠的会话过程时自动展开，支持跨虚拟列表定位。
- 文件正文与行号栏使用相同背景，深浅主题切换时同步更新。普通文件可编辑，支持选择、复制、撤销与重做；变更、历史引用及演示快照保持只读。
- 文件标签按语言类型启用 gpui-kit 内置的 Syntect 语法高亮，支持 Rust、Python、JavaScript／TypeScript、JSON 等常见格式；无匹配语法时按纯文本显示。

### 文件编辑与关闭确认

- 普通文件标签中的修改留在编辑缓冲区；文件名前显示圆点，`Ctrl+S` 保存成功后圆点消失。保存保留原有 LF／CRLF 换行和 UTF-8 BOM，不清空撤销记录。
- 关闭单个未保存文件时，显示文件名及“保存／不保存／取消”。保存失败时保留文件标签、编辑内容与提示框；不保存仅丢弃缓冲区，不修改磁盘文件。
- 切换会话／项目、新建会话、关闭全部文档或退出窗口时，若将关闭未保存文件，统一显示不列文件名的提示，按钮为“确认／取消”；确认丢弃未保存修改后继续，取消则保留当前会话与标签。标签菜单提供“关闭所有文件标签页”，固定会话标签始终保留。
- 文件有未保存修改时，自动刷新不会覆盖编辑缓冲区。保存前复查原磁盘版本；文件被外部修改、移除、改指向或只读时，保存报错并保留内容，不静默覆盖。若有冲突，可复制需要保留的内容，取消或不保存关闭后重新打开磁盘版本。
- 对编辑内容添加评论时，仍生成不可变快照；后续保存、撤销或放弃编辑不会改写已有评论引用。

## 配置命令的目标

下表用于无参数的配置命令；`/advisor configure` 为明确列出的例外。

| 命令 | GUI 目标 |
| --- | --- |
| `/model`、`/models`、`/switch` | 模型服务与注册；首次加载后自动完成跳转 |
| `/fast`、`/slow` | 速度与服务等级，包括 `tier.*` 和 Anthropic 慢速设置 |
| `/effort`、`/thinking` | 模型 → `defaultThinkingLevel` |
| `/modelpreset` | 角色与提示词 → 模型预设相关设置 |
| `/advisor configure` | 角色与提示词 → `advisor.*` |
| `/mcp` | MCP |
| `/lsp` | LSP |
| `/skills` | 技能 |
| `/plugins`、`/plugin` | 插件 |
| `/tools` | 工具调用 |
| `/settings` | 常规 |

`/effort high`、`/fast on`、`/modelpreset save name` 等带参数的命令继续由 OMP 执行。没有 GUI 对应功能的命令也保留原生执行方式，不因包含相似关键词而重定向。

速度配置页保存全局或项目的默认设置，是否生效由提供商及模型决定；它不是对当前会话立即执行 `/fast` 或 `/slow` 的开关。

## 模型、子智能体与角色

### 选择和注册模型

输入框模型菜单按提供商分组，使用所选环境的 OMP 返回的已配置可用聊天模型，不用附带的公开服务目录充当可用模型列表。模型切换后重新读取推理档位；`auto` 使用 OMP 的自动强度。档位以具体模型为准，例如已验证的 DeepSeek 模型使用 `off / low / high / max`，另有 `auto`，不统一套用 `xhigh`。

通过 `/model` 打开服务注册，可管理提供商连接、认证引用、API 格式及模型参数。服务目录合并本机目录与附带的公开元数据；尚未注册的新内置服务可能需要更新附带目录，也可使用自定义服务。

### 新建或编辑子智能体

1. 在设置中选择全局或当前项目范围，进入“角色与提示词”。
2. 点击“新建子智能体”，直接打开表单，无需先填写外部名称框。点击已有子智能体也使用同一类表单编辑。
3. 填写名称、职责说明和系统提示词。名称限制为 80 字符以内的字母、数字、`-`、`_`；`main` 和 `sub` 是保留名称。
4. 选择继承父会话、已配置模型或 `@角色`，并按需选择该模型支持的推理强度。
5. 保存后写入当前范围的 `agents/<名称>.md`，列表自动刷新。新建时不覆盖同名文件；编辑保存到原文件路径。

必填项和保存失败在表单内显示。未修改的高级头部字段及优先模型列表保持保留；`tools`、`spawns`、输出 schema 等尚无专用控件的字段可在原生文件中维护。

### 关联角色与模型

在“角色与提示词”点击“角色与模型关联…”，逐项选择模型及推理强度，可添加自定义角色。候选按角色需要的模型类型筛选，例如聊天、搜索或语音。

“继承／默认”会移除当前范围的显式覆盖，让 OMP 使用其他范围或默认选择。未改动的角色和优先候选列表保留；修改某项后，表单将其保存为所选的单一模型，可包含推理后缀。高级多候选列表及备用链仍可在原生配置中维护。

角色关联写入 `modelRoles`，子智能体使用 `@角色` 引用该关联，两者分别保存。修改默认角色不等于立即切换当前会话的活动模型。

## 设置范围与保存方式

| 内容 | 位置与保存方式 |
| --- | --- |
| OMP 全局配置目录 | 通过本机 `omp config path` 获取，不假定固定用户目录 |
| 普通全局设置 | 调用 OMP `config set` / `config reset` |
| 普通项目设置 | 当前会话执行目录下 `.omp/config.yml` 或已有 `.yaml`，按字段修改 |
| 模型提供商注册 | 全局 `models.yml`，保留未知字段及未修改参数 |
| 角色模型关联 | 当前全局／项目配置文件的 `modelRoles`，检查外部修改冲突 |
| 子智能体、技能和提示词 | 当前范围的 `agents/*.md`、`skills/<名称>/SKILL.md`、`SYSTEM.md`、`APPEND_SYSTEM.md` |

旧工作树会话的项目设置仍写入其原执行目录。没有当前项目时禁用项目范围；提供商注册只开放全局范围。环境变量和启动参数可能覆盖文件中的值。

文件型配置保存前检查外部修改，使用锁、备份和原子替换；备份与锁位于 GUI 数据目录的 `config-backups`。文件冲突时重新读取后再编辑。模型注册保存后，空闲会话重新连接，正在运行的任务不被强制中断。

网络搜索提供服务、凭据、SearXNG 地址及备用顺序表单；凭据通过 OMP 原生 `auth import` 保存。LSP/MCP 高级服务器配置使用 YAML/JSON 编辑器；插件调用本机 `omp plugin`，支持全局及项目范围。其他未提供专用表单的数组和映射使用 JSON 编辑。

## 数据目录与限制

GUI 默认数据目录为 `%LOCALAPPDATA%\OMP GUI`；`--data-dir <目录>` 优先于 `OMP_GUI_DATA_DIR`。演示模式默认使用其下的 `demo` 子目录，显式 `--data-dir` 则使用指定目录。一个数据目录同时只有一个可写窗口。

- `workspace.json` 保存项目、会话、消息、评论、草稿、界面偏好及历史快照，后台顺序写入并原子替换。
- 原生 JSONL 会话保存在 `omp config path` 返回目录下的 `sessions/<项目目录编码>/`；GUI 不再传入独立的 `--session-dir`。`omp-sessions/<会话 ID>` 仅可能保留旧版迁移备份；`worktrees/` 仅为旧版本工作树。
- 文本选区使用 UTF-8 范围及摘要定位；重复片段无法唯一映射时保留原文和快照，不猜测位置。
- Windows 换行仅在生成展示用 Diff 时归一化，历史快照保留原始正文。
- 文件预览仅支持 UTF-8、单文件不超过 2 MB，文件枚举最多 5000 项；当前不提供完整 IDE 工程编辑功能。
- LaTeX 公式暂显示原文。固定使用的 gpui-kit 0.8.1 提供解析扩展接口，没有内置公式排版控件。
- OAuth 和其他敏感交互认证在 OMP 终端完成。GUI 不自行确认工具授权；未覆盖的高级配置可继续通过 OMP 原生文件或终端维护。
