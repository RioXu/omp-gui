OMP GUI v0.9.0 改进电脑操作提示、思考展示和任务查看。下载 `omp-gui-0.9.0-windows-x86_64-setup.exe` 后安装，升级和卸载保留会话及配置。

- Computer use 在会话中显示截图、点击、按键等文字操作记录，不在 GUI 内存储和呈现截图。本机 Windows 操作期间显示屏幕边框、顶部提示、点击位置及按键提示；远端会话不会在本机误显示提示。
- 正在生成的思考默认滚动展示最新五行，点击可展开全文；已完成思考默认只显示居左的“思考过程”。预览与全文使用相同 Markdown 排版。
- 任务按钮移至输入框右上方，点击打开最多 360 px 宽的竖版任务浮层，覆盖会话而不挤动输入框；保留阶段、状态、详情和备注，支持外部点击或 Esc 关闭。
- 上下文状态移至模型名左侧。分支保持只读；修复流式更新导致搜索跳转和选区阅读位置变化。
- 模型角色表单补全未配置的内置角色，保留自定义角色及模型优先级。
- 提供显式可选的 GPUI Fast 实验后端，默认后端保持原有选择；原生基准结果及限制见验证记录。

远端管理协议保持 5，安装包内含同版本、同提交的 Linux x86_64 服务。Windows 程序在本机构建、打包并验证安装／升级／卸载，Linux 服务由 GitHub Actions 构建。

支持 Windows 10 1809 或更新版本及 Windows 11 x64。安装包不附带 runtime DLL；若缺少 `VCRUNTIME140.dll`，请安装[微软官方 x64 运行库](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)。本地模式需 OMP 和 Git，远程模式另需 OpenSSH、远端 OMP 和 Git。程序与安装包尚未代码签名。

使用 PowerShell `Get-FileHash <安装包> -Algorithm SHA256` 与 `SHA256SUMS` 核对。验证范围和边界见[验证记录](https://github.com/RioXu/omp-gui/blob/v0.9.0/docs/testing.md)，操作方式见[使用说明](https://github.com/RioXu/omp-gui/blob/v0.9.0/docs/usage.md)。
