OMP GUI v0.9.2 增加项目菜单、会话全名提示和桌面完成通知。下载 `omp-gui-0.9.2-windows-x86_64-setup.exe` 安装或覆盖升级，会话与配置保留。

- 项目右键菜单可新建会话或从 GUI 移除项目。移除保留 OMP 原生记录和项目文件，清除 GUI 会话记录及归档状态；重新添加项目后重新导入。
- 侧栏会话名显示不全时，悬停片刻显示全名，与 Git 分支提示效果一致。
- 流式输出保持阅读位置；模型输出结束或需要用户回应时跳转到会话末尾，后台会话不会抢走当前会话。
- 窗口未聚焦时显示“会话完成”或“会话待选择”的系统桌面通知，包含项目及会话名；点击打开对应会话并显示末尾，重复事件不重复提醒。横幅显示遵循 Windows 通知设置。
- 应用、窗口、任务栏和安装程序统一采用黄色倾斜 π 与感叹号图标，保留矢量母版和多尺寸透明 ICO。

远端管理协议保持 5。安装包内含相同提交、版本和协议的 Linux x86_64 服务；Windows 程序在本机检查、构建、打包及验证安装／升级／卸载，Linux 服务由 GitHub Actions 构建。

支持 Windows 10 1809 或更新版本及 Windows 11 x64；本机屏幕操作提示需要 Windows 10 2004 及以上。安装包不附带 runtime DLL，缺少 `VCRUNTIME140.dll` 时请安装[微软官方 x64 运行库](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)。本地模式需要 OMP 和 Git，远程模式另需 OpenSSH、远端 OMP 和 Git。程序与安装包尚未代码签名。

下载后使用 PowerShell `Get-FileHash <安装包> -Algorithm SHA256` 与 `SHA256SUMS` 核对。验证范围见[测试指南](https://github.com/RioXu/omp-gui/blob/v0.9.2/docs/testing.md)，具体操作见[使用说明](https://github.com/RioXu/omp-gui/blob/v0.9.2/docs/usage.md)。
