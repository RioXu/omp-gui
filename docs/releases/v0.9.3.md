OMP GUI v0.9.3 完善子智能体管理，并修复 Windows 路径显示和进程回收。

- 设置中的“子智能体”页支持搜索全局／项目范围的定义，编辑模型与系统提示词、修复源码或移除并保留备份。进入页面自动导入当前范围的内置定义，保留已有同名文件。
- “角色与提示词”只管理角色模型关联和系统提示词，移除智能体新建入口及列表。工具调用页增加 Eval 定位入口，沿用 OMP 的原生开关。
- 工作面板子智能体列表仅显示 role、状态和标题，点击在中央打开只读标签页，支持复用、切换和关闭，面板关闭后当前标签仍刷新。
- 项目右键菜单统一为左对齐纯文字，移除新建会话的图标和菜单分隔线。
- Windows 设置路径不再显示内部 `\\?\` 前缀，导入命令使用普通盘符或 UNC 路径。
- GUI 启动的 OMP 会话、配置查询和凭据导入按进程树回收，覆盖连接释放、包装进程先退出和 GUI 强制结束，避免遗留 Bun 等后代进程；其他会话独立管理。

GUI、共享核心和 Linux 服务版本同步到 0.9.3，远端管理协议保持 5。此源码版本的验证范围见 [testing.md](../testing.md)，安装包发布状态以 GitHub Releases 为准。
