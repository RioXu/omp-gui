OMP GUI v0.8.3 改为 Windows x64 安装包，下载 `omp-gui-0.8.3-windows-x86_64-setup.exe` 后运行安装。

- 支持安装、开始菜单／可选桌面快捷方式、覆盖升级和卸载；升级和卸载保留会话及配置。
- 安装包内含同版本 Linux x86_64 服务和许可文件，无需单独解压或搬运服务目录。
- 标题栏使用 gpui-kit TitleBar；输入框推理强度右侧显示只读 Git 分支，长名称可悬停查看。
- 模型服务新增“注入 Claude Code 身份”开关，本地 GLM 等非 Claude 模型使用 Anthropic 兼容接口时可关闭该身份提示词。
- 管理协议升级为 4，增加远端 Git 分支查询；远端服务需更新至匹配版本，默认自动部署路径会检测并更新。

支持 Windows 10 1809 或更新版本及 Windows 11 x64。安装程序不附带 runtime DLL；若缺少 `VCRUNTIME140.dll`，请安装[微软官方 x64 运行库](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)。本地模式仍需 OMP 和 Git，远程模式另需 OpenSSH。Linux 预编译服务基于 Ubuntu 24.04，ARM64 未进行实机验证，不提供该架构安装包。

使用 PowerShell `Get-FileHash <安装包> -Algorithm SHA256` 与 `SHA256SUMS` 核对。程序与安装包尚未代码签名。

详见[使用说明](https://github.com/RioXu/omp-gui/blob/v0.8.3/docs/usage.md)、[发布说明](https://github.com/RioXu/omp-gui/blob/v0.8.3/docs/releasing.md)和[验证记录](https://github.com/RioXu/omp-gui/blob/v0.8.3/docs/testing.md)。
