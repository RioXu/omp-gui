OMP GUI v0.8.4 改进远端性能与诊断排版，下载 `omp-gui-0.8.4-windows-x86_64-setup.exe` 后安装，升级和卸载保留会话及配置。

- 远端配置发现和历史投影使用有界缓存；会话索引按变化项目增量刷新并定期补查，大历史逐行解析。
- 文件通知合并变化路径，只重读受影响文件；缩短并发附着时的全局锁等待，监督服务空闲时按事件唤醒。
- 应用自定义远端通信升级为经校验的 rkyv 二进制协议 5，覆盖管理、文件监听、监督 socket 与远端聊天封装；OMP 原生 JSONL RPC v2 和磁盘格式保持兼容，附件直接传输原始字节。
- 后台任务和 LSP 等会话通知默认最多显示三行，点击展开／收起；搜索或评论定位时自动展开。
- LSP 长文件名自动换行；诊断采用任务面板式颜色和状态图标，分层显示行列、来源、规则代码、多行说明及关联位置。兼容 OMP 文本与标准 LSP 对象，Python 已用真实 Pyright 响应验证，另覆盖 C++、TypeScript、Rust 和 Ruff 格式。

管理协议从 4 升至 5，远端服务必须与 GUI 配套更新。安装包内含同版本 Linux x86_64 服务，默认部署路径会检测并更新；使用自定义服务路径时请同步升级。已有运行任务应先完成再切换服务版本。

支持 Windows 10 1809 或更新版本及 Windows 11 x64。安装包不附带 runtime DLL；若缺少 `VCRUNTIME140.dll`，请安装[微软官方 x64 运行库](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)。本地模式需 OMP 和 Git，远程模式另需 OpenSSH、远端 OMP 和 Git。Linux 服务由 GitHub Actions 在 Ubuntu 24.04 构建；不提供未经实机验证的 ARM64 包。

使用 PowerShell `Get-FileHash <安装包> -Algorithm SHA256` 与 `SHA256SUMS` 核对。程序与安装包尚未代码签名。

验证范围包括 Windows 145 项默认测试、Linux 95 项核心测试、原生通知绘制、真实 Pyright 响应和四项真实跨主机 SSH 回归；合成历史传输基准不代表整体性能改善比例。Windows 在本地构建并打包，Linux 服务与 GUI 校验源码提交、版本及协议一致。

详见[使用说明](https://github.com/RioXu/omp-gui/blob/v0.8.4/docs/usage.md)、[远程连接](https://github.com/RioXu/omp-gui/blob/v0.8.4/docs/remote.md)、[发布说明](https://github.com/RioXu/omp-gui/blob/v0.8.4/docs/releasing.md)和[验证记录](https://github.com/RioXu/omp-gui/blob/v0.8.4/docs/testing.md)。
