OMP GUI v0.9.5 优化长过程记录，并完善会话跟随与用户输入管理。

- 过程记录连续滚动，仅渲染可视区域及少量预加载步骤；长工具文本使用只读编辑器的可视行排版，保留全文。过程和工具文本不分页，消息历史仍每页最多 100 条。
- 在最新页底部跟随模型输出，上滚暂停、回到底部恢复；保持键盘焦点及已有文字选区。主会话和子智能体均适用。
- ask 选择 Other 后输入的文字显示为用户消息，保存重载和历史同步后保留且不重复；发送失败时保留输入。
- 未指示的追加输入可单项取消，撤回成功后文字和附件恢复到输入框，保留已有草稿。
- 空输入框按 ↑ 恢复本会话用户历史，↑／↓ 浏览；编辑后恢复普通方向键，补全菜单优先。
- 搜索和评论定位可滚动到内层过程步骤，文档统一说明分页与虚拟化的适用范围。

提供 Windows x64 安装程序和 SHA256SUMS，安装包内含同提交的 Linux x86_64 服务。三个组件版本均为 0.9.5，远端管理协议保持 5。虚拟化不减少完整历史的首次读取和解析成本，本版未新增实机帧率基准。

使用细节见[使用与配置](https://github.com/RioXu/omp-gui/blob/v0.9.5/docs/usage.md)。
