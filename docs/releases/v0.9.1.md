OMP GUI v0.9.1 修复模型输出期间的阅读位置跳转，并改善思考内容的区分。下载 `omp-gui-0.9.1-windows-x86_64-setup.exe` 安装或覆盖升级，会话与配置保留。

- 正文流式输出、工具活动和回合完成保持当前会话、键盘焦点及阅读位置，无需选中文字；即使原先停留在已显示内容的底部，也不会被后续输出自动带到结尾。
- 本次运行中已展示的过程记录和思考预览在完成后保持原状，避免自动收起挤动阅读位置；可手动展开或收起。历史过程仍默认折叠。
- 思考预览与全文使用比正文小一级的次级色文字和清晰边框，保留 Markdown 排版及最新五行预览。过程记录原样显示模型文本，包括单独的句点。
- 精简 README 并统一使用、架构、远程和发布文档；当前验证指南与历史测试／性能数据分开维护。

远端管理协议保持 5。安装包内含相同提交、版本和协议的 Linux x86_64 服务；Windows 程序在本机检查、构建、打包及验证安装／升级／卸载，Linux 服务由 GitHub Actions 构建。

支持 Windows 10 1809 或更新版本及 Windows 11 x64；本机屏幕操作提示需要 Windows 10 2004 及以上。安装包不附带 runtime DLL，缺少 `VCRUNTIME140.dll` 时请安装[微软官方 x64 运行库](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)。本地模式需要 OMP 和 Git，远程模式另需 OpenSSH、远端 OMP 和 Git。程序与安装包尚未代码签名。

下载后使用 PowerShell `Get-FileHash <安装包> -Algorithm SHA256` 与 `SHA256SUMS` 核对。验证范围见[测试指南](https://github.com/RioXu/omp-gui/blob/v0.9.1/docs/testing.md)，具体操作见[使用说明](https://github.com/RioXu/omp-gui/blob/v0.9.1/docs/usage.md)。
