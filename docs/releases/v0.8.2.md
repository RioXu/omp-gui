OMP GUI v0.8.2 是 Windows x64 便携版，完整解压后运行 `omp-gui.exe`。随包提供 Linux x86_64 远端服务，首次连接无需在受支持的远端环境安装 Rust。

- 新增默认白、默认黑、曜石橙皮肤，统一配色与字体，并采用 OMP 程序图标。
- 原生排版行内和块级数学公式；思考正文以蓝灰色区分，输入框上方显示 OMP 当前工具动作摘要。
- 正文与输入框随窗口伸缩，两侧各保留 10% 留白；侧栏项目与会话以连续竖线表示层级。
- 修复会话拖选后选区消失，以及回复后定位原文／回应评论导致的崩溃。
- 优化流式解析、后台保存、缓存和动画绘制；原生隔离基准在 60Hz 屏幕上验证标签／弹窗的 P95 供帧间隔分别为 15.1／14.6ms，满足 60FPS 帧预算，仍可能出现少量长帧。
- 工作面板切页直接使用缓存，避免重复扫描和文档重读；弹窗保留流畅的打开／关闭过渡。
- 支持 SSH Linux 工作环境、原生会话同步及 GUI 所属空闲连接的显式释放；运行任务和其他终端占用继续受保护。

本版仅发布 Windows x64 客户端与 Linux x86_64 服务；ARM64 未进行实机验证，不提供该架构发布包。

便携包需要本地 OMP 和 Git，远程模式另需 OpenSSH。Linux 预编译服务基于 Ubuntu 24.04，较旧 glibc 环境可自行构建并使用 `OMP_GUI_REMOTE_BINARY` 指定服务。

下载 ZIP 和 `SHA256SUMS` 后，可用 PowerShell `Get-FileHash <ZIP文件> -Algorithm SHA256` 核对。升级时保留 `%LOCALAPPDATA%\OMP GUI` 数据目录。Windows 程序未进行代码签名。

验证记录与限制见 [testing.md](https://github.com/RioXu/omp-gui/blob/v0.8.2/docs/testing.md)，详细功能见 [usage.md](https://github.com/RioXu/omp-gui/blob/v0.8.2/docs/usage.md)。
