OMP GUI v0.9.4 优化长会话展示、子智能体标签页和思考搜索。

- 主会话与子智能体每页最多展示 100 条消息，支持前后翻页及回到最新。完整历史仍保留，模型上下文不变。
- 子智能体沿用主会话的输入卡片、正文留白与可折叠过程记录，并使用虚拟列表和正文缓存。
- 当前页的消息正文与思考内容均可搜索，命中后自动展开、高亮和定位；流式新增命中不会主动打断阅读。工具参数、工具输出及其他页不在搜索范围内。
- 历史评论可自动定位到对应页，模型完成或请求交互时返回最新内容。
- 文档集中说明分页与搜索范围，将旧验证结果归档，并明确 GUI 分页不等于远端传输分页。

提供 Windows x64 安装程序和 SHA256SUMS，安装包内含同提交的 Linux x86_64 服务。GUI、共享核心与 Linux 服务版本均为 0.9.4，远端管理协议保持 5。
